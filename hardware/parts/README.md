# Part diagram

[`hardware/generate.py`](../generate.py) membaca SVG pada folder ini untuk menyusun diagram wiring. Nama file part aktif harus tetap tersedia di sini.

| Nama dasar | Isi | Penggunaan |
| --- | --- | --- |
| `uno-r3` | SVG | Arduino Uno R3 |
| `l298n` | SVG | Driver H-bridge L298N |
| `tt-motor` | SVG | Motor gearbox TT |
| `ky-033` | SVG | Bentuk modul sensor biru empat pin pada diagram |

Koordinat konektor diambil dari elemen pada SVG. Folder ini berisi empat sumber grafis yang diperlukan generator dan lisensinya; diagram bukan proyek wiring native Fritzing.

## Atribusi

Sumber dan nama pembuat tiap part tercantum di [panduan hardware](../README.md#sumber-part-dan-reproduksi). Ketentuan pustaka Fritzing disimpan dalam [LICENSE-fritzing.txt](LICENSE-fritzing.txt). Aset pihak ketiga mengikuti ketentuan sumber masing-masing.
